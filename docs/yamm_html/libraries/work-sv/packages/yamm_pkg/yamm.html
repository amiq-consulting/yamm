Class yamm_pkg::yamm

  • yamm_pkg :: yamm_buffer

    • yamm_pkg :: yamm

Top level class, acts as the full memory. This is the only level on which static buffers can be allocated

Functions

function void
build(string name, yamm_size_width_t size)

Function that initializes the memory, setting a name and a size for the memory as well as creating a free buffer over the entire memory span, supporting allocation and making the memory usable. Can only be called once.

function bit
allocate_static_buffer(yamm_buffer n_buffer)

Returns:

Returns 1 if the buffer was allocated or 0 if it overlaps at least partially other allocated buffer

function void
reset()

Can not be used if build wasn't called. Function that deallocated all non-static buffers and also clears the contents and all buffers allocated inside static buffers

function yamm_buffer_q
get_static_buffers()

Returns:

Returns the queue of static buffers that are stored in memory.

Return type:

yamm_buffer_q

function bit
write_memory_map_to_file(bit recursive = 0)

Function that dumps memory to file starting with the level it is called on. Can be done recursively if bit is set.

Returns:

Returns 1 if done successfully, or 0 otherwise
