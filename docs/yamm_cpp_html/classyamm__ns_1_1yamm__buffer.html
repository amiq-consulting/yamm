◆ deallocate()

bool yamm_buffer::deallocate ( yamm_buffer *  buffer)

This function tries to deallocate a buffer allocated in the memory.

The buffer can be a direct child of the level the function is called from, or a child of any deeper level of that memory. In the second case the deallocation is delegated to the level that directly contains the buffer, so the buffer is always removed from the correct list.

A warning is given if the buffer contains other buffers inside.

Parameters
bufferThe buffer that is going to be deallocated
Returns
It returns 1 if successful. It returns 0 if the specified buffer can’t be found or is a static buffer. It also returns 0 if the buffer is not allocated anywhere inside this memory (a warning is given in that case).
